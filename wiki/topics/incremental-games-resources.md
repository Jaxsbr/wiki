# Incremental Games: Resource Systems

Part of the [Incremental Games](incremental-games-overview.md) research set.

---

## Currency Tiers

Most incrementals use a layered currency structure:

### Primary Currency
The main resource generated by the core loop. Everything else is derived from or spent on this.
- Cookie Clicker: **cookies**
- Clicker Heroes: **gold**
- Antimatter Dimensions: **antimatter**
- Kittens Game: **science** (late game hub) / **catnip** (early survival)

### Secondary Currencies
Unlock specific sub-systems; often require converting primary currency.
- Cookie Clicker: **milk** (from achievements → CpS bonus), **magic** (wizard tower mini-game)
- Clicker Heroes: **hero souls** (prestige currency; buys Ancients)
- Kittens Game: **culture** (unlocks social techs), **faith** (unlocks unicorn branch)

### Prestige Currencies
Earned only on reset; permanently modify future runs. The genre's most powerful currency type.
- Cookie Clicker: **heavenly chips** (from ascension; each = +1% permanent CpS)
- Clicker Heroes: **hero souls** (doubles as both secondary AND prestige currency)
- Antimatter Dimensions: **Infinity Points** (1st prestige), **Eternity Points** (2nd), **Reality Shards** (3rd)
- Realm Grinder: **gems** (reincarnation currency), **research** (ascension currency)

## Resource Generation Methods

### 1. Manual Clicks
The player clicks a button. Generates primary currency at a fixed per-click rate. Rate scales with "click upgrades." Most relevant in early game. Examples: the Cookie (Cookie Clicker), the Big Red Button (A Dark Room).

### 2. Buildings / Generators
Purchased objects that generate currency per second automatically. The backbone of idle income.

Standard building pattern (Cookie Clicker buildings as canonical example):

| Building | Base Cost | Base CpS | Notes |
|----------|-----------|----------|-------|
| Cursor | 15 cookies | 0.1 | Automates clicks |
| Grandma | 100 | 0.8 | First "human" generator |
| Farm | 1,100 | 8 | Each tier ~10× prior cost |
| Mine | 12,000 | 47 | Income tier ratio ~1/3 |
| Factory | 130,000 | 260 | |
| Bank | 1.4M | 1,400 | |
| ... | | | (20 buildings total in v2.052) |

The ~10× cost per tier and ~1/3 income per tier is calibrated so players spend meaningful time at each level before unlocking the next.

### 3. Multipliers
Applied to generators' base output. Stack multiplicatively.
- **Building-specific**: "+50% Grandma CpS" (only affects one building type)
- **Global**: "×2 all production" (rare; very powerful)
- **Conditional**: "×1.01 per building owned" (scales as game grows)
- **Prestige**: permanent across runs (e.g. +1% per heavenly chip)

### 4. Generators of Generators (Abstraction Layers)
The most powerful structural idea in incrementals: resources that generate generators.

Antimatter Dimensions canonical example:
```
8th Dimension → produces 7th Dimension
7th → produces 6th
...
2nd → produces 1st
1st → produces Antimatter
```
Each tier's count determines the *rate* of production for the tier below. Buying one 5th Dimension increases 4th Dimension production — not antimatter directly. This creates compound growth and a natural reason for numbers to accelerate.

Cookie Clicker's "synergy upgrades" achieve something similar: owning Grandmas boosts Farm production, owning Farms boosts Grandma production — cross-generator dependencies.

## Resource Conversion Chains

Many deep incrementals use **A → B → C chains** where each resource is a converted form of the prior.

### Why conversion chains are satisfying:
1. **Makes abstract numbers concrete**: "wood → planks → buildings" is meaningful; "number → bigger number" is not
2. **Creates pacing bottlenecks**: you can be rich in wood but poor in iron, creating varied decision pressure
3. **Progression visibility**: unlocking a new conversion step feels like a paradigm shift
4. **Optimization depth**: players can optimize conversion ratios, not just raw production

### Kittens Game conversion chain (simplified):
```
Catnip (gather) → Meadows (boost) → Food (consumption) → Population
Population → Workers → Mining, Woodcutting, Science work
Wood + Minerals → Workshops → Efficiency upgrades
Science → Techs → New resource types (iron, coal, oil, uranium...)
Oil → Steamworks → Catnip efficiency (closes a loop!)
```

The game's complexity comes from loops within loops — later resources feed back to affect early ones.

### Universal Paperclips conversion chain:
```
Wire → Paperclips (manual) → Operations+Creativity → Projects/Upgrades
Paperclips → $ (sales) → More wire
Trust → Processors/Memory → Operations ceiling raised
```
Each stage restructures what matters.

## Soft Caps and Diminishing Returns

Incrementals use soft caps deliberately to:
1. **Signal prestige time** — if growth feels slow, it's time to reset
2. **Extend content lifetime** — prevent players from exhausting content too quickly
3. **Create strategic texture** — "do I fight through the soft cap or reset?"

### Types of soft caps:

**Exponential cost scaling** (universal):
Price = BaseCost × Multiplier^owned
As you buy more of anything, each unit costs exponentially more. Eventually the cost curve outpaces the income curve — this IS the soft cap.

**Galaxy upgrades** (Antimatter Dimensions):
Each "Galaxy" (an acceleration purchase) costs progressively more of a special resource. Early galaxies are cheap and powerful; late galaxies are expensive and marginally better. Forces prestige.

**Diminishing multipliers**:
Some upgrades give +10%, +8%, +6%, +4%... instead of constant +10%. Each subsequent purchase of the same type is worth less. Used to make diversified investment more efficient than stacking one type.

**Logarithmic scaling**:
Reward = log(input) — common for prestige currency formulas. Doubling prestige currency requires 8× more cookies (Cookie Clicker), 4× more (Realm Grinder), or 128× more (Egg, Inc.) depending on exponent.
