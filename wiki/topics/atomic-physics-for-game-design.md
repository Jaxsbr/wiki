## Quick-Reference: The Scales of the Atomic World

| Scale | Size | What Lives Here |
|---|---|---|
| Nucleus | ~1–10 fm (femtometers) | Protons, neutrons, quarks, gluons |
| Atom | ~1–5 Å (angstroms) | Nucleus + electron cloud |
| Molecule | ~1–100 nm | Atoms bonded together |
| Nanoparticle | 1–100 nm | Clusters of atoms/molecules |
| Visible world | > 1 mm | What we can see unaided |

## The Cast: Major Particle Types at a Glance

| Particle | Charge | Mass | Role |
|---|---|---|---|
| Proton | +1 | ~1 amu | Nuclear identity (Z count) |
| Neutron | 0 | ~1 amu | Nuclear glue + mass |
| Electron | −1 | ~0.00055 amu | Chemistry, bonds, charge |
| Up quark | +2/3 | tiny | Component of protons/neutrons |
| Down quark | −1/3 | tiny | Component of protons/neutrons |
| Gluon | 0 | 0 | Carries the strong force |
| Photon | 0 | 0 | Carries EM force; light |
| Neutrino | 0 | ~0 | Emitted in beta decay; ghostly |
| Positron | +1 | ~0.00055 amu | Anti-electron; annihilates on contact |

## The Four Forces at a Glance

| Force | Relative Strength | Range | Carrier | Role |
|---|---|---|---|---|
| Strong nuclear | 1 (reference) | ~1 fm | Gluon | Holds nucleus together |
| Electromagnetic | ~1/137 | Infinite | Photon | Bonds, light, chemistry |
| Weak nuclear | ~10⁻⁶ | < 0.1 fm | W/Z bosons | Radioactive decay |
| Gravity | ~10⁻³⁸ | Infinite | (Graviton, unconfirmed) | Negligible at atomic scale |

**Game relevance:** Four forces = four resource/damage types. Strong = binding energy (structure integrity); EM = attack/defense (charge interactions); Weak = decay/corruption (time-based degradation); Gravity = macro-level only, negligible for atomic gameplay.

## Game Design Themes by Concept

| Concept | Core Game Mechanic Idea |
|---|---|
| Electron shells | Upgrade tiers with capacity limits (K=2, L=8, M=18…) |
| Valence electrons | Bonding slots — how many connections an entity can form |
| Radioactive decay | Time-based resource depletion; half-life countdown timers |
| Half-life | Probability-based expiration (not guaranteed, statistical) |
| Isotopes | Same entity, different stats (same Z, different mass/stability) |
| Fission | Area-of-effect chain reaction: one split triggers more |
| Fusion | Combining two units creates one more powerful (with energy cost) |
| Critical mass | Threshold mechanic: below threshold = stable; above = cascade |
| Quantum superposition | Unit exists in multiple states until observed/measured |
| Quantum entanglement | Two remote units share state — change one, change both |
| Quantum tunneling | Bypassing barriers at low probability; infiltration mechanic |
| Pauli exclusion | No two units can occupy identical states — diversity bonus |
| Binding energy | Energy cost to disassemble a structure; stability as HP |
| Electronegativity | Faction affinity — how strongly an entity attracts resources |
| Noble gas stability | "Full shell" bonus: complete set = immunity/invincibility |
| Decay chain | Sequential transformation: A → B → C → stable end-state |
| Chain reaction | Exponential amplification above critical threshold |
| Ionization | Stripping an electron = losing a defensive layer |
| Excited state | Temporary power boost; must return to ground state (cooldown) |
